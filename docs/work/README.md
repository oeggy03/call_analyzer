# Multi-session work

Create a note here only when the work will span more than one session, or another agent must resume it. Do not add one for a routine change.

Use `docs/work/<short-slug>.md`. Delete it when the work is done. If a decision should outlive the task, move that decision to `docs/decisions.md` and the user-facing rule to `docs/behavior.md`.

```markdown
# <slug>

## Goal

## Progress

## Decisions

## Remaining

## Verification
```

`Verification` lists commands actually run and what was not run.
